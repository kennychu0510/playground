# Draw Wheel Bike

Vite + TypeScript source for the Draw Wheel Bike sim.

## Dev

```bash
cd sims/bike-wheel-app
npm install
npm run dev
```

## Build (GitHub Pages output)

```bash
npm run build
```

Writes static assets to `../bike-wheel/` with base `/playground/sims/bike-wheel/`.

## Play

1. Draw a closed wheel silhouette on the pad → **Apply** (or skip and ride the default circle).
2. **Gas** / **Brake** (or ←/→, A/D; Space = brake). **R** resets.
3. **Draw wheel** anytime to swap shapes mid-ride.
